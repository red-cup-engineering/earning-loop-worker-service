- `admission`: Both pure plans and all additional interfaces accept host configuration only. If configuration is absent or enabled is not exactly true or resourceAdmission.status is not exactly 'received', return null from plans; withIssuerSqliteStore returns {status:'not-configured'} without calling work or touching storage; private handler returns HTTP404 without storage.
